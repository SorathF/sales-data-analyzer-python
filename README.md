# Sales Data Analyzer-Python
A command-line tool that reads, validates, and analyzes retail sales data using Python, NumPy, and Matplotlib.
 
## Features
- Reads and validates sales data from CSV, skipping malformed rows and flagging invalid records (negative quantity/price) with a custom exception
- Computes total revenue, top-performing product, and revenue statistics (average, standard deviation) using NumPy
- Generates and saves a bar chart of revenue by product with Matplotlib
- Menu-driven interface for viewing summaries, top product, and generating charts
## Tech Stack
- Python
- NumPy
- Matplotlib
